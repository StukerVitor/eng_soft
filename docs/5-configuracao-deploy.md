
# ⚙️ Configuração e Deploy

## Dependências Principais

- `Node.js`, `Express`, `TypeScript`
- `React`, `Vite`, `TailwindCSS`
- `Prisma` + `SQLite`
- `Jest`, `Supertest`, `Swagger`, `Winston`

## Instalação
Veja instruções no arquivo `README.md` ou `1-visao-geral.md`

## Execução

```bash
npm run dev     # Inicia API local
npm run test    # Executa testes
npm run build   # Transpila TS
```

## Deploy sugerido
- Backend: Railway, Render ou Docker
- Frontend: Vercel ou Netlify
